# ClashKingAssets

This directory bundles the `troops/` and `leagues/` assets from
[ClashKingInc/ClashKingAssets](https://github.com/ClashKingInc/ClashKingAssets)
at commit `6da8ce864afe2b4510d3342e1c7374e48d7f5a49`.

Credit: ClashKing Inc. and the ClashKingAssets contributors. The upstream
project welcomes reuse and requests credit. See [UPSTREAM_README.md](./UPSTREAM_README.md)
and [LICENSE](./LICENSE) for the original attribution and GPLv3 license.

The files are available from the UI under `/clashking-assets/troops/` and
`/clashking-assets/leagues/`. The imported files are unmodified. The bot build
also converts troop icons to 96x96 PNGs for Clan Castle base-post graphics.
